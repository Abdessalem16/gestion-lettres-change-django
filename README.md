# Gestion des Lettres de Change

Application web développée avec Django pour gérer les lettres de change.

## Fonctionnalités

- Authentification utilisateur
- Création de lettres de change
- Gestion des informations du tireur, tiré et bénéficiaire
- Suivi du statut : En attente, Payée, Impayée
- Génération de lettres de change en PDF
- Base de données SQLite
- Interface web responsive

## Technologies

- Python
- Django
- SQLite
- HTML / CSS
- JavaScript
- Bootstrap
- ReportLab
